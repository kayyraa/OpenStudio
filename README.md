# Open Studio

Open Studio is a browser-based digital audio workstation for making music.

It aims to provide a simple but powerful workflow for arranging samples, creating notes, recording audio, and working with instruments and effects directly in the browser.

## Features

* Timeline-based arrangement
* Piano roll
* Sample playback and editing
* Synth instruments
* Plugin system
* MIDI-style note recording
* Microphone recording
* Per-note controls and automation
* Audio effects
* Tempo and playback controls

## Tech

Open Studio is built with standard web technologies:

* HTML
* CSS
* JavaScript
* Web Audio API
* Canvas

No large framework is required.
